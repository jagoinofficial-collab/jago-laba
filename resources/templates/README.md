# Template bersama

Folder ini untuk template dokumen bersama yang baru. Template halaman Konveksi tetap dimiliki `app/Modules/Konveksi/Views`; halaman Marketplace ada di `app/Modules/Marketplace/Views`.

Jangan memindahkan dokumen pelanggan atau hasil cetak ke folder template. File runtime tetap memakai lokasi lama sampai migrasi storage tersendiri disiapkan.
